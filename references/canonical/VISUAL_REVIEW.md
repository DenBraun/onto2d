# Visual pathway evidence

Relay transmission, species-specific cortical organization, corticogeniculate feedback and FEF-to-V4 modulation retain their separate contexts. Predictive coding is an interpretation with unresolved discriminating evidence. A correlation-based input assignment does not by itself establish a unique causal mechanism.

The selected preparation Methods of [Denman and Contreras 2015](https://doi.org/10.1523/JNEUROSCI.0027-15.2015)
identify acute recordings in anesthetized adult GN220 Ntsr1-Cre mice. Isoflurane
is reduced after electrode placement and adjusted against the local-field-potential
pattern. These recordings do not directly measure awake attention; the activated
pattern does not establish physiological equivalence with an awake preparation.
The source record retains exactly which Methods were read and which analyses
remain outside this review.

The current [visual pathway evidence records](visual-review.json) contain the sources, scope and
remaining experimental questions. See [the graph data guide](README.md) for
claim admission and reproducibility.
