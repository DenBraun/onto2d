# Onto2D History Case Pages

This app provides dedicated pages for all 24 registered history cases. Each
page is rendered from the shared validated registry and a presentation-only
content layer.

- The primary overview is [`apps/history-atlas/`](../history-atlas).
- `external-cases-catalog.js` validates registry data and supplies explanatory
  copy without duplicating taxonomy metadata.
- `external-cases.js` renders case classification, maturity, evidence,
  analysis support, navigation, and available resources.
- Case plans live in the [history portfolio](../../docs/history/PORTFOLIO.md).

Planned case pages describe bounded research designs. Only registry paths that
resolve to existing Model Packs or Explorers are presented as available.
